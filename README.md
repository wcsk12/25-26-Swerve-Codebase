# FRC Team 8116 Hatchet Robotics and FRC Team 8430 The Hatch Batch

## Project Overview
This repository contains the 2026 swerve drive codebase utilized by FRC Team 8116 Hatchet Robotics and FRC Team 8430 The Hatch Batch. This project aims to develop a robust and efficient swerve drive system that enhances the robot's maneuverability and performance in competitions.

## Project Structure
- `src/`: Contains the main source code for the swerve drive.
- `docs/`: Documentation related to the project.
- `tests/`: Unit tests for verifying functionality.
- `scripts/`: Helpful scripts for setup and deployment.

## Prerequisites
- Java 11 JDK
- Gradle 6.0 or higher
- A compatible FRC robot controller

## Getting Started
To get started with the swerve drive code, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/wcsk12/25-26-Swerve-Codebase.git
   cd 25-26-Swerve-Codebase
   ```
2. Ensure the prerequisites are installed.
3. Build the project:
   ```bash
   ./gradlew build
   ```
4. Deploy to the robot controller.

## Development Commands
Here are some helpful commands for development:
- Compile the code: `./gradlew compile`
- Run tests: `./gradlew test`
- Generate documentation: `./gradlew dokka`
